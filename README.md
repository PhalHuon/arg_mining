# Sentiment Analysis Web Application

## Live Site
[https://phalhuon.github.io/arg_mining/](https://phalhuon.github.io/arg_mining/)

## Overview
This web application performs sentiment prediction on input texts. It classifies the sentiment into **three classes** (e.g., Positive, Neutral, Negative) or based on **emotion sentiment** categories.

## Features
- **Input:** Text comments or reviews entered by users
- **Sentiment Classification:** 3-class sentiment prediction or emotion-based sentiment
- **Dashboard:** Visual summary of sentiment analysis results with charts and tables
- **User-friendly interface:** Easy to input data and interpret results
## Note
- This project is open-source and free to use.
